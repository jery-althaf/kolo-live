## 📝 Quick Customization Guide

### Change Colors:
```css
/* In the <style> section, update: */
--primary: #0066FF;        /* Your brand blue */
--accent: #00d4ff;         /* Accent color */
--gradient-start: #667eea; /* CTA start color */
--gradient-end: #764ba2;   /* CTA end color */
```

### Change Headline:
```html
<!-- Line ~450 in PREVIEW-complete-design.html -->

</h1>
```
